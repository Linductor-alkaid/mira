持续工作需要身份连续性、经历查证、对象关系、环境认知、待办恢复和能力复用。
六类分别规定权威来源、写入时机、可用查询键、可见范围与变更传播。
普通用户偏好继续使用 Preference，按其主体、适用范围与来源查询。它可以作为
用户画像上的一个有来源属性供给，Agent 的人格由宿主配置提供。

| 类别 | 权威源与写入 | 索引与读取 | 纠正、失效与验证 |
| --- | --- | --- | --- |
| 人格 | 宿主的版本化 Agent 配置。授权维护者更新身份、语气和角色约定。聊天推断只能提出候选。 | 按租户、Agent ID 与生效版本加载获准配置，由宿主形成角色约束。 | 替换配置使依赖旧版本的待发送投影失效。验收重载、回滚和历史文本无指令权。 |
| 事件记忆 | EventStore 接纳原始事件。结算后按提交水位提炼 Episode 或会话片段，记录来源事件和结果。 | 按授权 Task/Session、时间、事件类型和 ID 查证。关键词找相关片段，语义索引适用于单独的派生摘要。 | 按来源去重。删除影响记录、摘要、索引和在途结果。验收重开、重复提交和旧记录不会回灌。 |
| 社交对象画像 | 受授权的稳定对象 ID 和字段级断言。自述、用户确认与推断保留各自证据。关系有独立端点、来源和有效期。 | 在授权社交环境内按对象 ID 及别名解析，再按属性和时间查。相似度用于候选排序。 | 同名有歧义时由宿主澄清；跨域关联需要显式授权和身份依据。验收撤权后缓存和派生索引失效。 |
| 世界模型记忆 | 观察和可验证结果维护 EnvironmentFact/ApplicationFact 与 AppModel。当前会话的 WorldState 随观察推进。 | 按稳定环境、实体、属性和有效时间读取；环境可指工作区、设备、应用或社交空间。 | 观察缺失、版本变化或事实到期触发重新核验。验收同名环境隔离及旧状态无法直接触发动作。 |
| 目标记忆 | 任务、承诺及重复计划由确定性 owner 接纳，使用稳定 ID、状态、期限、下次触发、授权和去重身份。 | 按归属、未完成状态及到期时间读取，语义召回提供背景。执行前核对部署授权与当前目标版本。 | 重启恢复未完成状态，按去重身份处理到期；变更、取消和兑现优先于历史文本。到期派发见 M30-37，主动输出与打断预算见 M33。 |
| 技能记忆 | 可执行 Skill、工具、Workflow 本体来自注册表和发布目录。验证结果按任务与资产版本沉淀 Procedure、SkillHint 或 RecoveryLesson。 | 按能力、环境、适用版本、前置条件和失败签名找候选；从当前已授权注册表解析实际执行入口。 | 发布、撤回或换版本使旧执行索引失效，旧经验可带版本解释。验收已撤回能力无法调用。 |

## 提交、检索和恢复

宿主绑定当前 Principal、tenant、Task、Session 和精确 allowlist。分类和对象匹配均
在 ACL 内收窄候选。一条已提交事件可以派生多个知识候选，各类按自己的写入门槛、
来源与有效期校验，再提交到既有 Memory 写入管线。目标和配置类的状态变更由对应
owner 处理，候选摘要仅可引用其已提交版本。

每类独立生成有界候选，按组分配记录和文本预算，再交 Gateway 计入完整请求预算。
有确定性键的读取优先走结构化匹配。专用索引是可重建投影，其更新身份包含来源、水位
和版本。重建时应用删除与撤权屏障。工件正文继续通过引用读取，按既有规则脱敏和计量。

索引的前导键跟随各自的授权与读取边界。事件索引以 Session、事件类型、时间和序列
支持分页，任务通过稳定关联索引读取。画像以授权环境和对象 ID 查字段，别名索引
返回有界候选。世界事实以环境、实体和属性查有效区间，并保留记录时间。目标的主键
由租户、用户和目标 ID 绑定，按归属、未完成状态及下一次到期顺序读取。重复计划的一次触发
以计划 ID、版本及计划触发时间去重，恢复仅恢复待办状态。技能经验按资产 ID、版本
与环境索引，能力词和失败签名用于寻找相关候选。人格配置由宿主以 Agent ID 和版本
管理，Gateway 依请求绑定的配置版本复核。

记录的保留期沿已有类型策略。活跃任务和未兑现承诺进入受配额保护的状态集合。
画像撤权、环境或资产撤回通过对应 owner 使依赖投影失效。M31 按类别计量派生索引、
工件与版本所用空间，并处理回收。

首个增量按宿主配置用现有 MemoryKind 为事件、世界事实、技能经验（以及可选的用户
偏好）配置召回组。同一工作内的首查与模型追加查询都留在这些组和原 allowlist 内。
每组文本和记录总量独立封顶，累积结果去重，Gateway 按组分别准入。其余类别按 M30
工作项逐步交付。

M30-11 由宿主加载并激活版本化人格目录。任务绑定解析器供给租户、Agent 的当前配置
和授权探针，Gateway 将其作为受预算保护的宿主指令。人格身份和激活快照由目录维护；
快照在重新激活历史版本时仍以本次激活为准。回放记录只提供提示摘要，产品配置文件由
宿主负责。使用方式见[人格配置 API](../api/model-agent-loop.md#宿主管理的人格dec-120)。

M30-17 提供事件切片作为事件片段的取证入口。现有日志在重开时重建 Session/Task/type
索引。已授权的 Record 按 task 读取并保存扫描水位，同轮分页固定上界，墙钟范围
在有界扫描内验证。M30-12 接通 SQLite 会话片段与 FTS5。宿主按固定来源水位重建
整个有界会话前缀。作用域授权、正文检查、片段与索引事务，以及重放擦除屏障沿 DEC-122。
M30-39 在交互结算后自动推进至多八个同一快照的 Record 页。每页沿原合并管线提交，
同一任务向不同获准范围提取时使用独立水位。宿主可启用持久页回执，在相同绑定下恢复
固定快照。六类专用候选汇集及整条自动恢复仍归 M30-03 和 M30-38。
见 [DEC-141](../decisions/DEC-141-automatic-record-pages.md) 与 [DEC-157](../decisions/DEC-157-scoped-durable-record-pages.md)。

M30-18 接通社交身份目录。版本化别名按租户与经授权的社交环境共同索引，返回确定性
候选及歧义。对象和环境擦除保存持久屏障。M30-19 将字段断言提交给现有 IMemory，按
环境内对象 ID 与精确字段预过滤，再按有效时间和记录时间读取。每条断言保留一份来源事件，
同一字段可同时持有自述、用户确认和推断。字段与来源经宿主校验，自动模型提取不能创建
这类记录。M30-20 以独立有向对象对 scope 保存关系断言，按谓词、有效时点和记录时点
查询。对象擦除用两端索引在同一记忆库内清理出入关系，待擦除端点封闭相关读取与写入。
M30-21 为目录和记忆库保存配对及擦除意图。目录先持久关闭对象或环境，记忆清理确认后
结算意图。重开须先恢复未结算擦除。运行时的授权和撤权联动仍归 M30-13。

M30-35 通过消息来源和不透明账号 ID 精确解析当前交谈对象。已核验的多个来源账号可以
绑定同一对象并按账号召回画像字段。同名别名仍保留歧义。跨来源推断、指代归因及自动
画像更新见 [M30 自动记忆设计输入](m30-memory-automation-references.md)。

M30-40 从已持久化的会话事件建立消息与发言者关联，保存来源账号和原事件摘要。
精确会话查询提供有界证据，账号接纳与证据提交同事务，擦除后的旧消息无法重新归因。
见[消息证据 API](../api/durable-memory-host.md#索引社交消息证据)。

M30-41 从同一会话证据读取当前发言者，并将显式账号提及、早期引用消息和正文别名
分别关联到证据或候选。别名保留同名歧义，已擦除的引用失效。见
[参与者解析 API](../api/durable-memory-host.md#解析当前发言者和引用对象)。

M30-42 使用经核对的当前消息与有界会话历史自动提取正文引用。模型给出原文片段和
可选前序行号，目录返回别名候选或发言证据。处置保留模型推断来源，推断期间被擦除的
消息会使结果失效。见[正文引用提取 API](../api/durable-memory-host.md#自动提取正文中的对象引用)。

M30-22 以独立环境和应用 scope 保存世界观察。实体和属性在精确 scope 内索引。读取先
选择对应时点的最新已知观察，再核对有效区间。缺失、过期或歧义返回重新观察信号，旧观察
保持可按历史时点查证。M30-23 将信号接入 WorkflowRuntime 的 Navigate 入口。
安装时的 AppModel 内容摘要参与应用 scope，进程内的安装世代约束计划与派发。
失效的事实或不一致的读屏快照触发新观察，再按该观察规划，派发前复核当前授权。

M30-24 由独立 SQLite 目标库保存一次性任务和承诺。宿主按租户、用户和目标 ID 接纳
稳定来源，按归属和状态列出记录，并以截止时间索引发现待处理事项。结算和擦除持久化，
擦除保留身份屏障。M30-25 在同一目标库接通固定 UTC 间隔计划，登记的触发与下一次
截止时间一起提交。计划版本约束待登记触发，重复登记返回持久回执。M30-26 接通一次性
目标纠正和已送达提醒回执。纠正保留旧版本，提醒计数由回执计算；擦除清理两者的历史。
提醒回执的送达端由宿主接入。M30-37 交付从持久目标自动发起任务的接线，供 M33 复用。

M30-27 增加本地时分和星期计划，使用宿主提供的版本化时区规则计算 UTC。夏令时缺口
跳过，回拨选较早时间。规则耗尽后保留已登记回执，宿主换版可恢复下一次触发。

M30-28 提供目标存储授权入口。宿主从认证身份指定精确归属。读写、分页和回执重试
均在 SQLite worker 内向宿主复核当前策略，按资源及操作分别准入。存储的授权决定
仅覆盖这次操作，后续派发前仍需当前授权。见[宿主 API](../api/durable-memory-host.md#目标存储授权)。

M30-43 为到期一次性目标保存派发准备身份和提交回执。准备限于当前待处理版本，同版本
重试复用操作 ID。待派发查询省略已提交或还需对账的旧版本，兑现仍由结算证据推进。
见[一次性目标派发 API](../api/durable-memory-host.md#一次性目标的派发回执)。

M30-44 让已获宿主授权的派发器通过 Executor 周期检查一次性目标，使用稳定派发身份
调用宿主任务提交接口，确认后登记回执。M30-45 在同一派发器接入固定间隔和日历计划。
每次触发先保存独立操作 ID，得到提交确认后才推进计划。版本变化后可登记已确认的历史
提交，历史回执不改变新版本的时间。执行端的协调层接线由 M30-37 跟踪。见
[到期目标周期检查 API](../api/durable-memory-host.md#周期检查到期目标和计划)。

M30-46 为一次性目标接通实际任务完成证据。协调层从已归属的 Runtime 任务写入无错误
完成事件，目标库按派发回执关联事件与原目标版本。文件事件库重开后可继续结算。
M30-47 让派发器按归属分页核对持久待结算目标。尚无证据的目标留待后续扫描，过期后仍
可按原完成时间补结算。见[目标兑现 API](../api/durable-memory-host.md#按任务完成证据兑现一次性目标)。

M30-48 在上述检查中增加 live 完成证据发布。派发回执和现行宿主授权约束协调层读取的
任务与会话，已持久化证据优先走重放路径。证据发布前 Runtime 丢失的窗口留待任务持久
对账接线处理。

M30-49 用派发准备事务区分首次提交资格和只读对账。配置对账回调后，未确认的派发沿
原操作 ID 查询宿主持久准入结果，在回执可用后继续结算。见
[派发对账 API](../api/durable-memory-host.md#按原操作-id-对账)。

M30-50 为对账提供持久的任务准入结果。稳定操作 ID 随 Runtime 命令传入，协调层核对
已生效的命令和归属后写入任务台账。查询可在新的协调层内恢复已登记的准入回执。
M30-51 允许在 Runtime 发布任务前确认同一台账回执，消除该入口先发布后登记的间隔。
见[协调层准入 API](../api/interaction-coordinator.md#持久任务准入回执)。
M30-52 为持久派发的任务绑定完成记录器，在 Runtime 发布成功终态前写入相同的验证事件。
如果 Runtime 在证据持久化后丢失，派发器可同时回填准入并兑现该目标。证据写入前丢失的
任务仍需通过可恢复执行重新验证。见[完成证据 API](../api/interaction-coordinator.md#持久任务完成证据)。

M30-29 以宿主技能目录的当前描述符定位 `Procedure` 记录，在精确学习 scope 内按版本化
记录 ID 查询。升级会切换索引，撤回和撤权会关闭当前召回，旧版保留作查证。运行入口仍由
已授权工具注册表解析。见[当前技能记忆 API](../api/workflow-contracts.md#当前技能记忆)。

M30-30 把学习 scope 纳入新 `Procedure` 记录与写入身份。SQLite 保留旧归属回执，已同步
的同 scope 旧记录或擦除结果继续幂等处理。新身份写入时预留空缺的旧身份，旧调用方随后
重试无法重新添加副本。不同 scope 使用各自的新身份，独立同步和擦除。

M30-31 为宿主提供按工作流版本和失败签名读取 `RecoveryLesson` 的入口。SQLite 在现有
记录上索引完整失败键，按精确学习 scope 查询。返回前复核权限、学习绑定、来源及文档内容。
历史记录通过原 ID 查证。见[按版本读取恢复经验 API](../api/workflow-contracts.md#按版本读取恢复经验)。

M30-32 接通自动升级。在学习 scope 内读取 run 当前的精确恢复经验，再以剩余额度补充
Episode。工作流等待世代、载体恢复世代或学习绑定变化会使迟到的续跑材料失效。

M30-33 记录技能调用的宿主提示。写入以成功子 run 的结算事件为证据，通过既有
consolidation 校验。发布摘要标签在精确 scope 与 `SkillHint` 分类内缩小候选，读取
复核当前授权和发布版本。见[技能提示 API](../api/workflow-contracts.md#记录和读取技能提示)。

M30-34 将发布投影、技能提示和恢复经验绑定到宿主指定的工作或社交环境。范围包含租户、
环境域和内部 ID，事件记忆仍使用原范围。重新绑定会阻止旧运行把经验带入新环境。
见[环境技能记忆 API](../api/workflow-contracts.md#按环境隔离技能记忆)。

## 执行与验收

复用记忆服务现有 Executor worker、取消句柄和 revision 检查。分组查询串行，有界
读取，组间检查取消、硬截止和工作版本；发布前再次复核。每个查询文本的存储读取共享
软截止，超时返回已收集结果并标记降级。底层错误保留给调用方。写入、擦除、关停、
资源所有权沿 DEC-101 和 DEC-107。配置及持久目标以可恢复状态表达，回放只重建状态；
