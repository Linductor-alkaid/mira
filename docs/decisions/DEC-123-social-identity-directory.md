# DEC-123：社交环境内的持久对象身份与别名

> 状态：Accepted
> 日期：2026-11-23
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-119](DEC-119-six-memory-systems.md)、[DEC-070](DEC-070-long-term-memory-behavior-contract.md)

## 决策

M30-13 的身份增量提供宿主拥有的 SQLite 社交对象目录。精确环境键由已认证的
租户 ID 和稳定社交环境 ID 组成。直属对象使用该环境内稳定的宿主内部 ID，相同 ID
可以存在于不同环境。宿主负责账号映射与鉴权，目录按完整环境键查询并拒绝跨环境
别名解析。同名只返回候选和歧义，模型和别名都不能确认对象身份或合并环境。

目录保存正版本号及经宿主核准的别名列表。较高版本原子替换别名，旧版本拒绝，
同版本同内容幂等。同版本冲突报告 DataLoss。别名索引按环境和规范名称查询，
折叠 ASCII 大小写与空白，其余字符保持原样。一个对象的规范别名唯一，并使用
既有敏感内容标记检查。查询有限额，截断前判断歧义。读取返回对象的版本供宿主复核。

对象或环境擦除在同一事务删除别名并登记阻止恢复的身份屏障。同一实例的擦除过程
暂停目录读写，失败后保留暂停直到宿主重开并补做擦除。目录只保存身份映射及其索引，
画像属性、关系断言、引文和时态进入既有记忆提交管线，由 M30-13 后续增量提供。
容量含对象、别名和屏障，空间回收按 M31 保留策略处理。SQLite 工作复用 Executor
StoreChannel，宿主消费结果并按已有顺序关闭。

## 验证

覆盖同名歧义及截断、跨租户和环境隔离、重开保留版本、幂等、旧写拒绝、容量拒绝、
对象及环境擦除、重开恢复后的拦截。证据见 M30-18。
