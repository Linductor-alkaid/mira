# DEC-173 宿主登记一次性目标的完成证据

> 状态：Accepted
> 日期：2026-11-26
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-149](DEC-149-verified-goal-fulfillment.md)、[DEC-150](DEC-150-goal-fulfillment-polling.md)、MIRA-20261126-011

直接使用对话循环的宿主可按已提交派发登记完成证据。目标库按授权、来源 Runtime、会话、
任务、序号和事件 ID 读取持久事件。宿主的验证器负责确认渠道送达或环境动作结果，并从
证据取得实际完成时间。原始模型发言与循环结算不能作为该接口的完成证据。

允许登记的完成时间介于派发提交与证据入库时点之间。使用现有验证完成事件，增加派发
operation 和来源事件定位。宿主事件的控制序号为零，协调器事件沿用原格式。事件稳定
身份与 ProcessCrash 持久确认沿用 DEC-149。目标库在登记之后仍可用原入口核对兑现，
包括进程重启后的周期检查。兑现时继续检查当前权限、派发版本、事件归属、撤销和到期规则。
相同的已兑现证据返回原结算，冲突证据显式拒绝。

直接集成的宿主应升级完成证据的写入方和兑现方。旧版读取器会拒绝宿主形态的事件。
SQLite 目标库沿用 DEC-149 的存储格式。
