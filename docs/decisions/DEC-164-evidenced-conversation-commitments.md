# DEC-164：从已结算终答记录一次性承诺

> 状态：Accepted
> 日期：2026-11-26
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-129](DEC-129-durable-goals-and-commitments.md)、[DEC-133](DEC-133-goal-store-live-authorization.md)、
> [DEC-156](DEC-156-m30-implementation-freeze.md)

`ConversationSettled` 在终答取得耐久追加回执时附上 `AssistantSpeech` 事件 ID 和会话序号。
引用为加法字段。缺少引用的历史结算仍可用于会话和 Episode 读取，本入口需要带引用的
`Answered` 结算。宿主按授权会话读取确切结算和终答两条事件，并复核运行、任务、世代、
终答轮次及事件顺序。仅接纳完整的终答正文。候选使用终答的逐字摘录作标题，截止和可选
过期时间由受信宿主根据上下文解释。宿主负责判断真正的承诺，普通模型输出本身没有准入权。

本增量每个已结算终答接纳一条一次性承诺。目标 ID 按归属和终答事件派生，来源记为终答
事件。目标存储沿原有事务、准入策略、配额和擦除屏障提交，并区分首次创建和幂等回执。
重试必须提供相同定义。纠正、终态和擦除继续依照原目标存储契约拒绝旧创建，避免恢复
到待完成状态。候选入口在取证前及向目标库提交前核验当前来源授权、取消和截止。

存储准入沿既有 worker 策略再次检查。结算后的生产事件选择、语义解释和跨重启消费由
M30-38 验收，到期执行和恢复由 M30-37 验收。重复计划和同一终答中的多项承诺继续由
对应的候选设计处理。
