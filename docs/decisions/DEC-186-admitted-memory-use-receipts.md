# DEC-186：已准入模型请求的记忆使用回执

> 状态：Accepted
> 日期：2026-11-27
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-070](DEC-070-long-term-memory-behavior-contract.md)、[DEC-101](DEC-101-memory-agent-context-admission.md)、[DEC-156](DEC-156-m30-implementation-freeze.md)

## 决策

Memory Agent 在召回候选旁保留记录 ID、版本与精确范围摘要，关联本次上下文条目 ID。
该元数据供宿主核对，模型输入沿既有 Layer 0 组装。Gateway 按实际 provider 保留进入
请求的记忆版本，且同一范围的同一记录版本在单次回执中只列一次。

当前任务、上下文和人格仍有效时，完成响应或达到输出 token 上限的响应可以产生使用
回执。预算丢弃的候选、未发送的请求、失败尝试、取消和迟到拒绝均不产生使用回执。回执
表示记录随获准请求交付，决策结果与是否采纳内容沿各自的审计记录解释。

回执向宿主提供原逻辑请求 ID、实际尝试 ID、选择摘要、时间及记录版本。宿主可在调用
结果中取得回执，也可通过已配置的有界回调接收。回调失败可诊断，已返回的模型结果
和回执可继续消费。审计事件只登记计数，精确记录引用留在授权宿主边界。

持久投影的去重键为原请求 ID、精确范围、记录 ID、版本。持久计数、当前版本与擦除
复核、已确认重要性继续由 M30-06 交付，供 M31 消费。
