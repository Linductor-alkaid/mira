# DEC-141：交互结算后自动处理多页事件

> 状态：Accepted
> 日期：2026-11-24
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-107](DEC-107-interaction-memory-lifecycle.md)、[DEC-121](DEC-121-indexed-event-slices.md)

协调层结算后用一次 Record 作业处理最多八个索引页。直接提交 Record 的宿主仍默认
每个作业一页，可在请求中设定有界页数。作业共用原 Executor worker、截止时间和取消
上下文。每页分别经过现有证据校验、提取、合并和写入，之后推进已提交的工作水位。
首个有后续页的查询固定同轮结束水位，后续页只扫描该快照。旧事件适配器仍处理一页。

返回结果合并该作业各页的处置，保留最后处理水位和是否仍有未处理页。某页失败时
返回错误，并在诊断中保留已成功页的水位；宿主重试从成功水位继续。达到页数上限时
成功返回 `more_pending`，由宿主视情况续跑。跨进程水位和六类提取路由见 M30-38。

M30-39 验收多页、固定快照中途追加事件、页数上限和后续页失败后续跑。
