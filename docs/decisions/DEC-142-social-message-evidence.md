# DEC-142：社交消息事件与发言者证据

> 状态：Accepted
> 日期：2026-11-24
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-121](DEC-121-indexed-event-slices.md)、[DEC-126](DEC-126-social-erasure-recovery.md)、[DEC-140](DEC-140-source-account-identity.md)

宿主从认证后的入站信封取得环境、会话和来源账号，在事件写入后提交事件 ID 与会话
序号。目录从授权的 EventStore 会话读取该位置，核对事件 ID、序号与会话。账号首次
接纳和发言者证据使用同一 SQLite 事务。证据索引保存来源会话、位置、事件摘要、来源
账号摘要和发言对象。原事件正文由 EventStore 持有，索引只保存定位与归因。

同一环境内重放同消息返回原证据，冲突的来源账号、事件内容或会话位置报错。按授权
环境和精确会话范围有界读取，结果按原事件序号排列。分页读已投影的证据，迟到补录按
原事件区间重查。宿主继续负责账号元数据的认证和会话归属。

目录迁移到 1.3，使用现有 Executor StoreChannel。对象擦除清除发言关联和事件位置，
保留作用域化的事件摘要屏障，阻止旧事件被重放成另一对象的发言。环境擦除删除索引
且沿用环境屏障。索引容量计入擦除屏障。原事件的保留和物理清理由其 owner 处理。

M30-40 验收发言者接纳、同会话多账号、有界召回、证据冲突、重开、旧库迁移和联合擦除。
正文提及、跨来源同一性推断、自动关系与画像更新仍由 M30-36 承接。
