# DEC-100：子代理自主发现与副作用执行

> 状态：Accepted
> 日期：2026-11-09
> 负责人：Mira Maintainers
> 冻结里程碑：M35
> 修订：DEC-099 的只读工具范围；不改变单层委派与 Executor 生命周期

## 决策依据

用户明确要求子代理按任务语义自行获取、选择并执行工具，包括写入、发布和任务执行。
用户与父代理不必预知完整工具集，也不逐项提供工具 ID 白名单。父上下文只保留目标、
委派句柄与有界结果，具体目录、schema 和执行往返留在子上下文。

## 决策

保留默认静态只读模式，新增显式 Discover 模式。可信资源工厂按 child goal/context
供应目录与受限执行闭包；这是能力边界，不是父代理枚举。子模型通过 discover_tools
分页读取描述（可接宿主语义检索），通过 load_tools 选择下一轮原生工具 schema。
选择是子模型的语义判断，框架不把字符串匹配冒充语义授权，也不承诺模型判断可靠。
可选宿主执行策略在每次调用前检查 goal、精确工具与参数；不是逐次人工审批。
目录中选中的副作用工具可以执行，不再硬编码拒绝 has_side_effects。

目录快照、分页、激活集与输出有界；未知身份、重复与递归委派工具拒绝。新增执行
必须通过既有 child worker，所有回调合作取消，资源适配仍留宿主。副作用工具必须
提供独立验证回调，返回 Applied / NotApplied / Uncertain。返回成功本身不是 Verify。
派发前持久记录精确工具身份、operation 和参数摘要；记录失败不派发。派发后的
验证失败、异常或未知结果将阻止后续工具、使 child 失败，并向父返回未知副作用标志。
取消不表示回滚；已验证效果计数与未知标志保留到取消终态。事件不保存参数/结果原文。
不自动重试工具或回放副作用；宿主负责目标资源互斥、幂等键和真实外部结果检查。

本次不增加递归团队、跨进程恢复或设备共享租约。MemoryEventStore 只作为进程内
fixture；生产持久性依赖真实 EventStore。见 [M35](../plans/m35-subagent-semantic-tools.md)。

## 备选与后果

父传工具 ID 白名单保留为兼容选项，但不作为自主模式的授权来源；将整个目录 schema
一次性注入父/子请求会抵消上下文隔离，因此采用子侧分页和原生 schema 激活。
只放开 has_side_effects 不能处理调用已生效但 receipt 丢失，故增加独立 Verify 与
未知效果封闭路径。公开 C++ 结构扩展需要消费者重编译，默认行为和 worker 拓扑不变。
宿主目录/执行闭包仍是可信计算基；本次不提供文件系统沙箱或模型语义安全保证。
