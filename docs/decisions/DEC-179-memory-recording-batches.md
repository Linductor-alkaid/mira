# DEC-179：统一处理已归类的记忆候选

> 状态：Accepted
> 日期：2026-11-26
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 替代/被替代：无

## 决策

M30-03 为授权宿主提供一个按输入顺序处理六类候选的入口。批次包含类型化候选和证据
定位，由宿主在既有 Executor 作业内提供当前操作、事实源和各类型所有者。批次逐条调用
既有所有者的写入入口，消费 Record 的受管作业结果。社交候选在交给目录前复核宿主当前
授权，目录继续核对原文、对象和擦除屏障。

每条处理过的候选保留原类型结果及 DEC-178 的处置汇总。单条失败由该位置报告。取消或
到期时停止发出后续操作，并返回已处理前缀；批次数量超限在写入前报告。重试沿各所有者
既有稳定身份和收据。批处理层不合并各库的事务，也不接纳模型直接写入的 MemoryRecord。

## 取舍与验证

在宿主边界 dispatch 类型化数据，让模型提议无法替换验证器和存储能力。独立结算避免
某类证据有误时重做已成功的其他写入。验收覆盖混合批、错误隔离、取消后缀、目标重放、
授权及证据拒绝。持久事件源、默认触发、模型语义分类和进程重启后的消费由 M30-38 验收。
