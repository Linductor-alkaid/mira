# DEC-121：有界事件切片与记忆取证水位

> 状态：Accepted
> 日期：2026-11-20
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-119](DEC-119-six-memory-systems.md)、DEC-088 与 DEC-101

## 决策

M30-12 的首个增量给 EventStore 增加可选的有界事件切片读取。宿主按现有授权选定
精确 Session，随后可用 Task、事件类型及墙钟区间收窄。MemoryEventStore 保存按
Session、Session/Task 和 Session/type 的序号有序索引。范围取证使用序号游标，
墙钟区间在有界扫描内过滤，旧日志缺失的时间在时间查询中省略。每页独立限制返回数、
扫描数与载荷字节，返回可复用的会话上界和已扫描水位，空页也可继续推进。固定上界允许在
并行追加期间完成一致的分页。

FileEventStore 的有界内存投影在正常打开和恢复时从同一日志重建，沿用原 wire、
完整性校验、耐久确认及读写栅栏。索引只保存位置引用。附加索引操作同步依附于现有
owner 和互斥边界，不增加后台线程或持久库。日志重写、分段归档及物理擦除归 M31。

受管 Memory Record 优先按当前已授权 Task 读取切片，成功结算后推进扫描水位，
还有待扫描证据时沿用原上界。切片排除记忆服务自身审计事件，单页处理额度较小也能排空。
支持的后端返回错误时将其交给调用方，未提供切片能力的既有后端继续使用旧 Session
分页。权限仍由宿主绑定与服务校验。清除记忆后的持久 scope 屏障继续禁止重建和新写入，
日志事件本身沿 EventStore 生命周期保留。当前切片返回证据事件，派生会话片段的持久
索引和联合擦除仍在 M30-12。

## 验证方式

覆盖多 Session/Task、类型和时间边界、固定上界、扫描耗尽空页、幂等追加、File 重开、
旧时间缺失与损坏拒绝。受管服务验证其他 Task 流量不占目标任务页、重复读推进水位、
删除屏障和旧后端兼容。证据记录在 M30 计划。
