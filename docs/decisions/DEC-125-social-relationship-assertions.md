# DEC-125：社交关系断言与双端点清理

> 状态：Accepted

> 冻结里程碑：M30
> 依据：[DEC-119](DEC-119-six-memory-systems.md)、[DEC-123](DEC-123-social-identity-directory.md)、[DEC-124](DEC-124-social-attribute-assertions.md)

## 决策

关系使用一条有方向的 `SocialRelationship` 断言。其精确 scope 绑定一个租户、一个
社交环境及该环境内有序且相异的两个对象 ID。宿主复核两个对象的授权及当前目录版本，
再提交稳定关系谓词和来源事件。跨环境、跨租户和自环拒绝。反向关系需要独立断言。
主张内容、来源类型、验证级别、有效区间和记录时间沿 DEC-124 独立保留。通用模型提取、
一般工作召回和跨对象的开放式遍历不接入该能力。

关系依有向对象对、谓词、来源类型和事件 ID 确定身份，使用现有内容门禁、不可变写入、停用、历史和
物理擦除。SQLite 按有向对象对、谓词与时间预过滤查询，并按两端索引对象擦除。对象
scope 擦除在同一记忆库事务清理属性及该对象的出入关系，历史和工件沿既有清理管线。
任一端点处于待擦除状态时，库内的关系读取与提交都拒绝。目录擦除仍由宿主先完成，
跨库失败恢复由 M30-13 后续增量接通。

## 验收

验证双端授权边界、方向和谓词过滤、独立证据、时态、幂等冲突、迁移、重开和两端擦除。
见 [M30-20](../plans/m30-long-term-memory-integration.md)。
