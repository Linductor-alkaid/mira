# DEC-122：持久会话片段索引与擦除重放

> 状态：Accepted
> 日期：2026-11-23
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-119](DEC-119-six-memory-systems.md)、[DEC-121](DEC-121-indexed-event-slices.md)、MNT-202611-MS-04

## 决策

增加 SqliteConversationIndex 作为可选的会话片段检索后端。宿主授权后按租户和会话
发起有界重建，从固定 EventStore 上界读取证据。复用会话投影和窗口分段，保留来源
ID、来源序号、角色及原始会话上界。存储前检查完整原文及片段的内容策略。输入事件数、
字节及持久会话/片段/屏障条目数受限。超过限额明确拒绝，保留已提交快照。

每个会话拥有稳定的 Session scope 摘要。会话水位、片段和 FTS5 更新在一次 SQLite
事务提交。较低水位拒绝，同水位同内容幂等，同水位内容变化报 DataLoss。按授权
Session 和匹配 Session scope 查询，全文索引以 scope 词项收窄，组合显式字面条件。
按最近来源序号及 ID 确定性排序。向量仅发出降级诊断，有文本条件时继续词法查找。
控制提交、读写和关闭复用 Executor StoreChannel。重建调用由宿主的受管工作执行。

会话擦除提交 scope 摘要墓碑并删除该 scope 的片段和索引项，保留会话归属映射。
索引擦除期间封闭本实例读/写入口，失败保持封闭，宿主重开后重放未清理意图。
MemoryAgent 宿主可注入片段索引，以既有持久擦除事件触发片段清理，初始化重放后才
对外提供索引。索引失败仍继续既有工件、偏好及长期记忆清理，再报告失败。跨库步骤
可重试，逻辑删除与物理空间回收分别结算。单独的用户/应用
scope 擦除不扩大为会话擦除。历史无 kind 的擦除回执也重放其摘要，避免遗漏旧会话
屏障。M30-09 管理重新接纳，M31 管理磁盘总量、备份及物理回收。

## 验证

验证来源序号、原生角色、固定水位及同水位冲突，跨租户/会话负向查询，全文和字面
过滤，重开、联动擦除、已有意图重放和过期重建拒绝。适用结果见 M30-12 与 MS-04。
