# DEC-167：从已记录用户消息提交人格建议

> 状态：Accepted
> 日期：2026-11-26
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-119](DEC-119-six-memory-systems.md)、[DEC-120](DEC-120-agent-persona-admission.md)、
> [DEC-156](DEC-156-m30-implementation-freeze.md)

宿主可将已持久记录的 `UserMessageInjected` 原文摘录提交为待审人格建议。入口从宿主
绑定确定租户、Agent 和当前生效版本，按精确事件位置核对运行、会话、任务、世代、原文
字节数与摘要。重复摘录须给出字节偏移。敏感标记和注入形态使用现有记忆内容检查。

建议 ID 绑定 Agent、基准版本和摘要、来源事件及摘录区间。读取前与交付前复核当前
授权和激活，交付前检查取消与截止。宿主接收器按建议 ID 记录和核对回执，保留基准版本
及来源坐标。基准版本或原始来源失效后，宿主在审查时重新核对当前状态。持久待审队列、
审查权限和清理由宿主的人格配置体系承担。

建议正文仅交给宿主接收器作为待审数据。维护者使用 DEC-120 的原有配置提交与加载路径
处理版本变更，Gateway 继续读取已激活配置。生产候选触发与重放由 M30-38 跟踪。
