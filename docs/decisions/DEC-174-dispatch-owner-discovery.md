# DEC-174 从目标库恢复派发归属

> 状态：Accepted
> 日期：2026-11-26
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-146](DEC-146-goal-dispatch-polling.md)、[DEC-150](DEC-150-goal-fulfillment-polling.md)、MIRA-20261126-013

`dispatch_owners` 从持久目标库分页枚举需要派发器的归属。纳入可派发的一次性目标、
已提交待核对的目标和启用的重复计划。未来到期的工作也纳入启动。已过期且尚无提交回执
的一次性目标以及无可派发时间的目标省去。每页按租户和用户 ID 排序，续页使用相同的
观察时点。列表只包含归属 ID。

授权型存储按每个实际存在的工作类别核对该归属的现有集合查询权限。至少一个类别获准
时才返回归属。游标仅使用已返回的归属，权限拒绝与授权器异常均省去对应类别。宿主据
此恢复 `GoalDispatchPoller`，后续读取、派发和兑现继续核对各自权限。

分页读取使用现有目标、计划和派发回执表。扫描范围受存储容量约束，授权结果按页复核。
翻页期间读取当前工作和授权，新增工作可以在宿主后续的归属发现中出现。
