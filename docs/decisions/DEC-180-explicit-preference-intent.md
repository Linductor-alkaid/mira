# DEC-180：偏好记住与纠正的结构化入口

> 状态：Accepted
> 日期：2026-11-27
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 替代/被替代：无

## 决策

M30-05 先接通已认证工作中的偏好记住与纠正。宿主传入结构化意图和提案 ID。协调层核对
当前主体与工作，Memory Agent 复核工作帧和原有 `mira.memory.manage` 授权，并从绑定
推导精确用户 scope。记住只接纳新偏好或确认相同偏好；现有值冲突时要求明确纠正。纠正须
绑定同一主张的当前记录 ID 与正版本。歧义和已过时的绑定都通过现有版本冲突返回。

新写入复用 DEC-109 的持久待审批提案。重复值可以返回无变更，提案阶段保持原记录与出处。
提案身份同时绑定意图和原有的主体、工作、内容及目标版本。同一意图可以重试。旧入口的
字段和身份摘要继续兼容。入口经宿主调用，现有决定接口负责审批。

## 验证与后续范围

验证从协调入口提交新记忆、处理重复与冲突、按精确版本纠正，以及拒绝跨用户和越权调用。
自然语言解释、逐记录遗忘与范围擦除回执继续由 M30-05 交付。
