# DEC-124：社交画像的字段断言与时态读取

> 状态：Accepted
> 日期：2026-11-23
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-119](DEC-119-six-memory-systems.md)、[DEC-123](DEC-123-social-identity-directory.md)

## 决策

宿主在已授权的社交环境内确认目录身份后，可为一个对象和一个字段提交来源事件。
画像使用 `SocialObject` 精确 scope，租户独立存放，主体由环境 ID 和对象 ID 组成。
新增 `SocialAttribute` 记录种类，字段键为有界 ASCII 标识符，值、来源类型、事件 ID、
有效区间和记录时间同时持久化。来源分别为对象自述、用户确认和推断，验证级别分别为
Observed、HumanConfirmed 和 Unverified。需由宿主校验事件归属与来源。通用模型提取
不能提交此种类，MemoryAgent 工作绑定也不接受画像 scope。

同一对象、字段、来源类型和来源事件对应一条不可变断言，经 MemoryConsolidator 内容
校验与 IMemory 提交。相同内容重试幂等，同身份不同内容拒绝。变化或纠正以独立事件
写入，保留各自证据与区间；读取返回符合条件的断言供宿主解释。允许经既有机制停用或
擦除记录。有效区间左闭右开；记录时间与有效时间可独立选择。默认读取当前有效且已
记录的断言。SQLite 以精确 scope 和字段过滤候选，走独立字段索引，不向量召回。

身份目录与断言存储由当前宿主共同管理。目录检查和权限复核由宿主完成。擦除首先停止
访问及在途操作，再落目录屏障并清理对应记忆 scope。联合擦除恢复、关系断言和运行时
准入由 M30-13 后续增量交付。

## 取舍与验收

复用记忆的版本、证据、保留与物理擦除通路。独立断言避免一般事实合并将证据、时态
或信任等级归到其他来源。验证稳定身份、不同来源与时态、幂等冲突、环境与租户隔离、
重开及按 scope 擦除。证据见 [M30-19](../plans/m30-long-term-memory-integration.md)。
