# DEC-154：在 Runtime 发布任务前持久化准入回执

> 状态：Accepted
> 日期：2026-11-25
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-072](DEC-072-autonomy-and-interruption-budget.md)、[DEC-153](DEC-153-durable-task-admission-receipts.md)

宿主可在现有 `SubmitTask` 命令中传入准入记录器。Runtime 先检查会话可接纳状态，分配
任务标识并构造准入时快照，再交给记录器。记录器返回成功后将任务放入 live 注册表并确认
命令生效；失败则返回命令拒绝，候选任务没有对外发布。旧的两参数提交入口沿用现有语义。

协调层为一个当前授权的归属与操作 ID 构造记录器。在执行时重新核对授权时效、Runtime
会话归属、操作标识和截止时间，并服从 DEC-153 的回执与查证契约。记录器持有事件库
所有权及必要的值快照。原调用的取消回调仍由原 owner 管理。记录器运行于既有 Executor
串行命令内，期间释放 Runtime 记录锁。宿主提供有界的本地记录器，禁止重入和等待同池
任务，正常关闭继续回收已接纳命令。

回执的持久确认是该路径的准入点。若在确认后、live 发布前丢失进程，新的协调层可查证
原任务标识和接纳时点，恢复后的任务执行仍遵守 M30-37 与 M33 的准入、验证和续跑规则。
写入失败或确认不明时，派发器沿 DEC-152 的原操作 ID 对账。此增量覆盖准入窗口，任务
终态证据的写入窗口仍由 M30-37 跟踪。

M30-51 验收有界记录期间的可见性、失败不发布、当前归属和重启回填。无需目标库迁移。
