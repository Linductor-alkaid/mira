# DEC-151：周期核对时自动发布到期目标的完成证据

> 状态：Accepted
> 日期：2026-11-25
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-149](DEC-149-verified-goal-fulfillment.md)、[DEC-150](DEC-150-goal-fulfillment-polling.md)

宿主可为既有 `GoalDispatchPoller` 配置完成证据发布回调。每次先在受信任务事件库核对
持久证据。若尚无证据，才读取仍匹配的提交回执，由宿主解析当前主体并调用协调层检查
回执指向的 live Runtime 任务。校验当前授权、会话与租户用户归属，并按 DEC-149 幂等
写入实际成功完成的证据。活跃、失败、已取消或已不在当前 Runtime 中的任务没有新证据，
保留待结算。宿主配置的发布与核对使用同一任务事件库。

调度回调尝试获取协调层准入锁，遇到并发准入时返回可重试的背压结果。这样协调层的
输入准备任务仍可使用同一 Executor 的剩余工作容量。

发布确认后再次读取并验证证据，再使用既有目标结算。发布返回确认但事件库没有该证据
时通过派发诊断报告错误。权限拒绝和写入错误可观察，在后续扫描重试。停机前已持久化的
证据可在重启后直接补结算，无需恢复 live 任务。所有步骤沿现有派发器的单次检查、
取消和截止时间执行。此次接线无目标库迁移。

M30-48 验收宿主配置一次后自动处理实际 Runtime 终态、无证据和并存未完成任务、授权
恢复、幂等回放及持久事件优先。生产自主任务准入及按原操作 ID 的持久任务提交对账仍由
M30-37 跟踪。
