# DEC-161：保留社交关系的前序发言证据

> 状态：Accepted
> 日期：2026-11-25
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-125](DEC-125-social-relationship-assertions.md)、[DEC-143](DEC-143-social-message-references.md)、[DEC-144](DEC-144-social-mention-extraction.md)、[DEC-160](DEC-160-evidenced-social-relationship-recording.md)

关系候选可引用同一授权会话中之前已索引的发言。自动入口使用当前消息和前六个事件位置
中的已索引文本消息，模型只看到局部行号、发言者槽位、文本和谓词词表。模型可为当前消息
的原文指称选择前序行，也可沿既有路径以文本别名解析。关系摘录须包含该原文指称。行号
只用于选择已加载的证据。宿主直接提交候选时提供目标消息定位。

目录以目标消息的已归因发言者作为另一端，复核目标事件的原始摘要和会话边界。自动路径
保存模型所见的发言证据快照，并在持有现有写入协调权时复核。提交前检查期限、取消、
事件匹配、会话归属及擦除状态。找不到仍有效的前序发言时保留未解析状态或返回证据
失效错误。已生效的条目可按原证据重试。输入和存储都不使用模型生成的对象标识。

推断关系按 `[主张事件, 前序发言事件]` 顺序保留 provenance。主张事件继续参与稳定关系
身份计算，附加证据不另建记录。原有单证据断言照常读取。带两条证据的断言使用记忆文档
1.7，SQLite 沿用已有的多证据索引。重放同一记录可幂等返回，改换证据需作为冲突处理。
双端擦除移除关系及其证据关联。`Inferred` / `Unverified` 继续表明模型的归因是候选。

生产宿主统一触发及跨账号同人推断仍由 M30-03 / M30-36 跟踪。
