# DEC-172 会话索引按水位续建

> 状态：Accepted
> 日期：2026-11-26
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-122](DEC-122-durable-conversation-index.md)、[DEC-171](DEC-171-conversation-speech-search.md)、MIRA-20261126-007

`rebuild` 从已发布水位读取新增事件，整批验证通过后提交。单轮事件或字节超限时保留
原水位。`advance` 可以分批提交连续前缀，返回已发布水位与本轮来源快照上界。
片段总量与单轮输入预算继续独立生效。可选的容量诊断回调在每次打开后首次容量拒绝时触发。

索引复用已经闭合的窗口，只有未闭合的末段参与后续分段。片段标识保留全局条目偏移，
因此到达同一水位时与整批生成的片段一致。会话归属、水位和来源锚点重新核对后才在
一个事务提交。来源须遵守追加日志契约，索引核对已发布水位的事件和最后一个投影片段的
末条来源。更早的已发布事件依赖来源持久性保证。

schema 1.3 从旧片段恢复已投影条目数。旧库第一次续建按现有分段配置核对末段，提交后
固定配置。会话与片段容量、擦除屏障均继续生效，失败保留现有快照。
