# DEC-178：六类记忆的宿主写入汇总

> 状态：Accepted
> 日期：2026-11-26
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 替代/被替代：无

## 决策

宿主从六类现有写入入口收集处置结果。统一报告按入口保留每次提交，分别统计实际生效、
未产生变更、待审批、拒绝、未解析和超限。已确认的幂等重放另计，用来解释未产生变更或
已在待审队列的条目。失败入口只记录错误码和原接口标记的可重试性。

报告只读取已结算的结果。各入口保留原始证据、授权、写入和恢复行为。社交报告中已进入
合并的行从合并结果计数，避免与原始行处置重复。通用 Record 同时汇总提取拒因和合并结果，
原有水位继续区分本批已完成与仍待处理。

## 取舍与验证

直接合并各写入存储会引入跨所有者事务。采用宿主侧汇总可把相同的处置语义用于交互反馈和
后续持久消费，同时保留每个所有者的重放边界。验收覆盖六类混合结果、审批与重放、社交
逐行去重、授权错误、容量和通用 Record 工具回执。默认事件调度及崩溃恢复由 M30-38 验收。
