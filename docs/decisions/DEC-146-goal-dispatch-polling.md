# DEC-146：一次性目标的周期到期派发

> 状态：Accepted
> 日期：2026-11-24
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-072](DEC-072-autonomy-and-interruption-budget.md)、[DEC-145](DEC-145-durable-goal-dispatch-receipts.md)

为已授权归属提供宿主启动的周期派发器。一次检查读取一页待派发目标，并按到期索引
推进游标，避免一个失败目标占用所有后续检查。每次检查由同一个外部 Executor 的
可取消延时任务承载。检查完成后才登记下一次运行，保留并消费定时任务的 future。
外部 owner 关闭派发器并等待在途检查后，才能关闭目标库和 Executor。

检查为当前版本准备派发身份，再调用宿主提交接口。提交接口按稳定操作 ID 对账和去重，
使用部署常驻授权，并对取消协作。收到确认即登记回执，提交结果不明时保留准备记录。
重试用同一个操作 ID。目标仍以独立结算事件兑现。派发器状态提供扫描数、提交数、失败数
和最近错误。任务拒绝、回执错误和取消当次检查均可观察。

M30-44 验收有界周期检查、顺序分页、失败后其他目标仍可推进、重开续派、取消及关闭。
协调层的生产提交实现和重复计划的执行接线仍归 M30-37，主动输出与注意力预算归 M33。
