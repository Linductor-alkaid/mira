# DEC-134：按当前发布版本读取技能记忆

> 状态：Accepted
> 日期：2026-11-24
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-119](DEC-119-six-memory-systems.md)、[DEC-040](DEC-040-tool-reference-and-skill-layer.md)

## 决策

宿主以精确技能名读取当前发布版本的 `Procedure`。可同时指定预期描述符摘要，约束到
具体版本。`WorkflowRuntime` 从学习配置取单一 scope，经当前授权后查宿主技能目录，
使用既有发布投影的版本化记录 ID 调用 `IMemory::query`。SQLite 在已授权 scope 内
使用主键过滤，沿用查询的擦除屏障、活跃状态和过期处理。读取核对归属、类型、记录 ID
和与该发布一致的规范化记录内容。只有当前处于有效区间的活跃记录可返回。

读取前和存储访问后分别检查宿主授权，返回候选前检查发布描述符和学习绑定仍有效。
授权拒绝或探针异常返回 `PermissionDenied`。尚未同步、已撤回、预期版本不符或已停用
时为空。目录继续由宿主在串行控制面持有。有界授权探针使用当前身份与策略。

沿用带事件证据的 `sync_skill_procedure_index` 和原记录身份。已落盘的技能记录可直接
读取。升级后的目录在新版投影写入前返回空，旧版仍可通过历史查询审阅。此接口给宿主
提供当前技能记忆数据，执行仍由已授权的工具注册表及既有准入路径处理。

## 验收

验收精确归属、持久重开、升级前后、撤回、读取中撤权、学习绑定变化，以及过期、
墓碑和不匹配记录的处理。见 M30-29。
