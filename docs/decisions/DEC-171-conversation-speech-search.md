# DEC-171 会话发言的索引与命中证据

> 状态：Accepted
> 日期：2026-11-26
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-122](DEC-122-durable-conversation-index.md)、[DEC-147](DEC-147-lexical-segmentation-and-query-composition.md)、MIRA-20261126-006

会话索引从用户消息和 `AssistantSpeech` 的文本字段派生可检索正文。工具调用和结算资料随
原片段保存，全文与精确查询均使用派生的发言正文。不同发言之间保留 FTS 词元边界。
纯工具调用需要宿主通道提供可读取的发言事件，通用索引按现有发言事件契约取证。

会话查询有词或相邻双字时优先使用这些单元，单字查询仍可检索。单元之间使用 OR，FTS5
按 bm25 排序，匹配证据包含实际命中的查询单元与原始 rank。scope 词项只负责授权范围
过滤，其权重为零。记忆库的词法配置沿用 DEC-147。

schema 1.2 在读写事务中从历史片段重建派生正文和 FTS。旧片段用既有角色及工具调用行
格式识别发言。与工具调用标记外观相同的历史自然文本可能被保守截去。新写入从事件的
独立文本字段取值。历史片段、水位、原始摘要和擦除屏障均可继续使用。
