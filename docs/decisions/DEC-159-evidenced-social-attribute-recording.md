# DEC-159：从已归因消息接纳社交画像候选

> 状态：Accepted
> 日期：2026-11-25
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-124](DEC-124-social-attribute-assertions.md)、[DEC-126](DEC-126-social-erasure-recovery.md)、[DEC-142](DEC-142-social-message-evidence.md)、[DEC-156](DEC-156-m30-implementation-freeze.md)

宿主可在一次已授权的会话作业中提交同一条已索引消息的字段和原文摘录。专用入口从
社交目录取得发言对象，并按会话、序号、事件 ID 和摘要复核原始文本。候选只包含字段名
和有界的逐字摘录。对象、来源、有效期起点和可信等级均由入口根据消息证据确定。一个
批次最多八个不同字段，整批结构和引用先验证，再进入记忆合并管线。

宿主也可传入允许提取的字段集合，调用 `infer_and_record_social_message_attributes` 单次
完成提取和提交。模型只收到当前发言的文本和字段词表，输出字段及逐字摘录。内容检查、
敏感数据配置检查、结构化输出和取消期限复用社交推断边界。语义只作为候选，目录和原文
在模型返回后仍由写入入口复核。

本入口产生 `Inferred` / `Unverified` 的社交属性断言。断言的稳定身份沿用对象、字段、
来源分类和证据事件。重复提交同内容幂等，内容改变返回冲突，独立来源可保留反证。
调用方直接获得 `ConsolidationReport`，包括每条候选的分类与处置。声明正文只写入原有
画像记忆库，复用禁存内容和注入筛查。回执可从现有持久 mutation 语义重试取得。

读取和准备证据期间不占用擦除锁。申请短时写入串行权后，在写入前复核消息归因和取消、
期限。目录查询和记忆提交分别通过已配对存储的 Executor StoreChannel，宿主在受管
作业内等待。擦除关闭同一入口并按原流程清理画像，关停需与在途写入结算。存储故障
与取消可能留下先前已生效的候选，入口在每条提交前复核取消和期限，宿主可按原消息重试。
生产宿主的统一触发、跨账号同人推断和
关系候选分别继续由 M30-03 / M30-36 跟踪。
