# DEC-182：宿主忘掉意图的派生失效与续办

> 状态：Accepted
> 日期：2026-11-27
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 替代/被替代：无

## 决策

当前获准工作的宿主可提交 User 或 Session 的结构化单条遗忘意图。服务从工作绑定推导
范围，复核 `mira.memory.manage`、记录与版本。操作 ID 同时绑定主体、范围和目标。
只接纳支持 DEC-181 原子擦除的后端。

服务先在控制日志登记派生失效意图。受影响的在途投影和缓存失效。服务擦除涉及该记录 ID 的
偏好提案正文，并按精确范围清除仅登记了范围依赖的压缩工件。源记录按 DEC-181 擦除。
相关记忆作业暂停至后端完成且控制回执确认。原事件和会话发言索引按各自来源契约管理。

重开按日志恢复派生失效和待处理范围。当前授权宿主用同一操作 ID 续办物理擦除。控制日志
只保存身份摘要和提案 ID，正文保留在各自工件。真实输入的目标解析与旧证据回灌阻断继续
由 M30-05、M30-09 和 M30-38 验收。

关联 [M30](../plans/m30-long-term-memory-integration.md#5-工作项)、
[DEC-156](DEC-156-m30-implementation-freeze.md) 和 [DEC-181](DEC-181-scoped-record-erasure.md)。
