# DEC-144：从已索引消息提取正文对象引用

> 状态：Accepted
> 日期：2026-11-24
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-114](DEC-114-extraction-model-supply.md)、[DEC-142](DEC-142-social-message-evidence.md)、[DEC-143](DEC-143-social-message-references.md)

宿主通过同一会话的事件与发言证据启动一次有界提取。输入包括当前消息和最多六条较早
消息，来源限定为已验证摘要的 `mira.social.message.received.v1` 文本事件。代号在请求内
区分发言者，平台账号和对象 ID 留在宿主。禁止内容检查沿用记忆提取契约。

模型只提交当前正文中出现的原文片段，以及可选的前序发言行号。宿主核对原文和行号，
用目录解析精确别名或前序发言证据。返回值将正文推断保留为候选，模型行号不会变成
平台认证引用。一个最多八项的回复通过现有结构化模型协议读取，无工具和远端存储。
推断前后复核参与过请求的消息证据，已擦除的来源使结果失效。宿主在现有 Executor
任务内调用，使用同一取消和截止时间。目录、画像和关系均不由本次推断修改。

M30-42 验收真实目录与事件日志上的离线模型回归，覆盖同名候选、群聊上下文、候选
原文、行号、越权来源、取消和擦除。真实平台接线、跨来源同人推断、自动画像写入仍归 M30-36。
