# DEC-150：周期核对已派发目标的完成证据

> 状态：Accepted
> 日期：2026-11-25
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-146](DEC-146-goal-dispatch-polling.md)、[DEC-148](DEC-148-recurring-goal-dispatch.md)、[DEC-149](DEC-149-verified-goal-fulfillment.md)

宿主可将受信的任务事件库绑定到现有 `GoalDispatchPoller`。派发器每轮最多核对一页
仍为 Pending、当前版本已有提交回执的一次性目标。SQLite 用归属、状态和目标 ID 索引
分页，按主键关联派发表。只发现候选，具体证据核对和写入仍分别用当前授权。候选不按
当前时钟排除已经过期的目标，兑现仍以证据中的实际完成时间判断。

核对复用 DEC-149 的完成证据及原版本结算。尚无证据时留待下次检查，其余错误通过已有
诊断报告并继续分页。各类检查有独立游标，在同一 Executor 定时任务内轮换起始次序。
扫描到末页回到起点，重启后重新扫描持久待结算集合。宿主可只启用结算检查。关闭时按
现有生命周期停止检查，证据读取、持久化与目标写入之间检查取消和截止时间。

M30-47 验收分页、过期后的合法补结算、重开、当前授权及现有派发共存。已派发任务的
完成证据由宿主记录，生产自主准入、持久任务提交对账以及完成事件的自动发布仍由
M30-37 跟踪。此增量无需迁移目标库。
