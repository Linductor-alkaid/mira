# DEC-140：社交来源账号与当前交谈对象

> 状态：Accepted
> 日期：2026-11-24
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-119](DEC-119-six-memory-systems.md)、[DEC-123](DEC-123-social-identity-directory.md)、[DEC-126](DEC-126-social-erasure-recovery.md)

宿主从已认证消息信封取得社交环境、来源命名空间、账号不透明 ID 和来源事件 ID。
账号键在租户和社交环境内精确匹配，可在首次看见账号时原子创建稳定对象。前台可用
消息信封解析当前说话对象；群聊显示名和文本提及沿原别名索引保留歧义。多个平台可
接入同一社交环境。已核验证据可在首次见到新账号时将它绑定到已有对象，后续该账号
独立解析到同一对象。绑定保留首个来源事件，重放和并发接纳复用原绑定。已有不同
对象绑定的账号返回冲突，待后续证据化归并支持可纠正的对象等价关系。
已配对的目录可以按账号召回当前精确画像字段，返回前复核账号绑定和对象版本。

账号索引保存作用域化摘要、对象与来源事件引用，接受宿主生成的稳定不透明账号标识。
独立容量包括对象擦除后留下的账号屏障。对象擦除清掉账号关联及事件引用，保留摘要
屏障，重放消息无法创建替代画像。擦除整个环境后清掉账号索引，由现有环境屏障挡住
重建。SQLite 目录迁移到 1.2，复用已有 Executor StoreChannel 和配对擦除事务。

M30-35 验收识别、同名隔离、可信新账号绑定、冲突、重放、重开、迁移和擦除。
自主跨来源推断、指代、画像和关系更新的后续验收见 M30-36，通用提取接线见 M30-38。
