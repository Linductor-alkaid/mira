# DEC-165：批量接纳同一终答中的承诺

> 状态：Accepted
> 日期：2026-11-26
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-129](DEC-129-durable-goals-and-commitments.md)、[DEC-133](DEC-133-goal-store-live-authorization.md)、
> [DEC-156](DEC-156-m30-implementation-freeze.md)、[DEC-164](DEC-164-evidenced-conversation-commitments.md)

宿主可从同一条已结算终答提交最多八项一次性承诺。批次共享一次结算和终答取证。
每项引用独立、不重叠的终答原文区间。摘录唯一时可省略字节偏移，重复摘录通过显式偏移
定位。宿主负责判断承诺语义、互相独立性和期限。

以原文顺序分配目标身份并返回回执。第一项沿用 DEC-164 的目标 ID，后续项按同一终答、
归属和顺序派生各自 ID。原有单项入口保持兼容。已保存的前缀可原样重放及向后追加，
改变已登记项或将另一项移入已有位置会冲突。原有单项如果对应终答中的后置承诺，批次
需要保留已登记的首项身份，冲突时保留原记录。擦除后的 ID 仍拒绝旧候选。

`SqliteGoalStore` 在既有 worker 内核对每项当前创建授权，再在同一 SQLite 事务以内逐项
检查冲突和容量。全部成功后提交，每项回执区分新建和幂等重放。任何失败均回滚本批新建
记录，已保存项照旧。继续由 M30-38 验收生产提取和重放，M30-37 处理到期执行。
