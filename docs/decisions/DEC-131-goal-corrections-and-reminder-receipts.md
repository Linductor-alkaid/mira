# DEC-131：一次性目标纠正与提醒回执

> 状态：Accepted
> 日期：2026-11-24
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-070](DEC-070-long-term-memory-behavior-contract.md)、[DEC-129](DEC-129-durable-goals-and-commitments.md)

## 决策

宿主可用新的来源事件纠正 Pending 目标的标题、期限及过期时间，沿用原归属、ID、
类型和创建时间。现行版本校验、保存旧定义、更新到期索引在同一事务提交。纠正历史
按目标和版本读取，可追溯此前的来源。原状态机继续禁止终态修改和重新激活。

宿主根据已送达的证据登记提醒，在 Pending 且版本匹配时接纳。目标和送达事件 ID 共同
确定提醒回执。相同重试返回已有回执；同 ID 不同版本或时间拒绝。提醒计数取自回执，
跨纠正和重启延续。目标擦除同时清理历史与回执，仍保留 ID 屏障。

每目标的纠正和提醒分别受限，SQLite 事务沿用 Executor StoreChannel。提醒送达、
权限、平台调度与当前授权由产品和 M33 处理。此处登记既有送达结果。

## 验收

验证旧库迁移、纠正历史、待办期限更新、并发去重、配额、终态及联合擦除。见 M30-26。
