# DEC-143：社交消息的发言者与引用对象

> 状态：Accepted
> 日期：2026-11-24
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-123](DEC-123-social-identity-directory.md)、[DEC-140](DEC-140-source-account-identity.md)、[DEC-142](DEC-142-social-message-evidence.md)

宿主对已建立发言证据的消息解析参与者。结果区分当前消息发言者和按输入顺序返回的
引用。平台显式账号提及按精确来源键解析，引用原消息通过同一会话的较早已索引消息
解析发言对象。两者各自返回已保存的证据。正文提取出的名称按原别名索引返回候选，
唯一候选仍保留别名来源，同名歧义不因候选截断而消失。

整个查询在同一目录工作单元内完成。一次最多 16 条引用，别名候选上限沿用现有 API。
缺失或已擦除的被引用账号和消息保持未解析。当前消息的缺失或擦除按原证据处理。
此入口只读取目录，未确认的引用无法创建身份、合并对象或写入画像。

M30-41 验收多人消息、账号提及、引用和别名歧义、跨会话拒绝、证据擦除后失效。
正文指代的模型提取、跨平台同人推断和自动画像写入由 M30-36 承接。
