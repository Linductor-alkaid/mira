# DEC-128：导航读取世界事实与重新观察

> 状态：Accepted
> 日期：2026-11-23
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-127](DEC-127-world-fact-address-and-freshness.md)、[DEC-028](DEC-028-navigation-planner-and-navigate-resolution.md)

## 决策

WorkflowRuntime 提供宿主显式安装的导航世界事实绑定。应用 scope 从授权租户、环境、
稳定应用 ID 和安装时的 AppModel 内容摘要派生。宿主用同一 scope 提交观察与读取记录。
Runtime 对导航结果的置信度回写延续安装摘要，宿主重新安装 AppModel 时重新计算摘要并
推进进程内世代。旧世代的计划和在途证据不能进入后续派发。

当前事实只有和宿主当前读屏快照一致且快照落在它的有效区间内，才可用于规划。记录
缺失、过期、歧义或与读屏不一致时，Runtime 通过 Executor 请求 `max_age=0` 的观察，
将该观察交给宿主识别。派发后的到达验证也使用新观察。授权探针、模型世代、截止时间
及取消在派发入口复核。已接纳动作沿现有协作取消与收敛契约完成，结果在继续前复核。
绑定模式继续使用既有工具 registry 和导航事件。未安装绑定的宿主继续使用原读屏入口。

## 验收

验证过期或换版后由真实观察重规划、存储授权与版本隔离、无法识别时无副作用、
观察中取消、派发前撤权、同 ID 边的换版失效及旧结果无法回写新图。见 M30-23。
