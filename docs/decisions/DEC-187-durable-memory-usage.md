# DEC-187：记忆版本使用次数持久化

> 状态：Accepted
> 日期：2026-11-27
> 负责人：Mira Maintainers
> 冻结里程碑：M30
> 依据：[DEC-156](DEC-156-m30-implementation-freeze.md)、[DEC-186](DEC-186-admitted-memory-use-receipts.md)

## 决策

SQLite 记忆所有者接收受信任宿主转交的 Gateway 回执。Gateway 回调只暂存回执，宿主在
模型调用返回后提交给已有的存储 worker，并消费写入结果。队列拒绝和超时沿存储 API 报告，
宿主可以用原回执重试。一个回执内的写入在同一事务结算。

记录所有者按 ID 读取当前记录的精确范围，核对回执中的范围摘要、版本、有效期和版本写入
时间，并检查擦除屏障。无匹配、已失效或正擦除的引用记为跳过。受信任宿主在读取时传入
当前获准的精确范围、记录 ID 和版本。范围不匹配和版本已失效时返回空。读到当前有效版本
但没有回执时，次数为零，最近使用时间为空。读事务在同一快照检查当前版本、擦除屏障和
统计值，支持只读诊断连接。

SQLite schema 1.11 在同一事务内保存去重行并更新使用次数和最近使用时间。记录 ID 在
库内唯一，去重键为记录 ID、版本和逻辑请求 ID，精确范围已由当前记录复核。一个请求的
首次入账时间固定，独立请求乱序到达时保留最大使用时间。删除源记录、版本更新或退出
Active 状态会在同一事务清除去重行及聚合值。迁移后旧记录从零开始，已确认重要性由
M30-06 的后续工作交付。
