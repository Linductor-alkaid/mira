# DEC-168：连续会话的宿主工具选择与人格提示

> 状态：Accepted
> 日期：2026-11-26
> 负责人：Mira Maintainers
> 依据：[DEC-056](DEC-056-continuous-conversation-loop.md)、[DEC-120](DEC-120-agent-persona-admission.md)、mira-bridge 宿主反馈

Continuous 会话中，合法工具往返是任务推进的一部分，继续服从 DEC-056 的持续模式语义。
工具执行成功也不能替代任务验证。原有每批协议边界、显式取消和宿主运行边界继续适用。
MIRA-20261126-001 中观察到的重复发送拆回模型对话完成判断、历史与提示，使用工具次数
判断完成的方案不采纳。

Continuous 使用独立版本的内置提示。模型应在仍能推进时持续行动，结合工具结果确认
目标是否达成，并在重复动作前核对其是否已生效。纯文本终答只用于工作完成或存在具体
阻塞的场景。显式 System 提示及绑定人格可提供与宿主通道相符的终答规则。

`ConversationLoop` 支持宿主在工具筛选完成后逐请求设置 `ToolChoice`。Required 和 Named
需要实际暴露的工具。提供者无视选项时，循环按现有恢复路径重试，未经准入的动作和普通
文本不产生工具副作用或已答复结算。未配置选择器时 `ToolChoice` 默认为 `Auto`。

若宿主通过 Gateway 提供当前有效人格，且循环使用默认提示，则由人格提供 System 文本。
显式宿主 System 提示和人格同时配置时，前者在前。无显式提示及人格时使用当前模式的内置提示。
